# 帧火花故事开发诊断系统规则草案

本文档用于规划「帧火花故事开发诊断系统」的材料阶段、诊断边界、nextStep 规则和后续改造顺序。它是后续修改 `materialRouter`、`guard`、prompt 和前端文案的依据，不代表当前代码已经全部实现。

## 一、系统新定位

系统正式名称为：

「帧火花故事开发诊断系统」

系统不再只面向完整剧本，而是面向影视故事从创意到剧本的开发全过程。用户可以提交一句话创意、故事概念、梗概、大纲、人物小传、世界观设定、剧本片段，也可以提交完整短片剧本或完整长片剧本。

核心原则：

- 用户可以提交不同阶段的故事材料。
- 系统先识别材料处于哪个开发阶段。
- 系统按材料阶段选择诊断标准。
- 不能用完整剧本标准去评价一句话概念、人物小传、世界观设定或片段文本。
- 不能因为材料短就自动判为短片，也不能因为材料有剧本格式就自动判为完整剧本。
- 诊断目标不是硬找问题，而是判断材料当前阶段是否成立，以及下一步该补什么。

## 二、材料阶段划分

### 1. 极短概念 / 一句话故事

对应 `materialForm`：`concept`

典型字数：几十字到 300 字左右。

诊断目标：

- 判断是否有最小故事前提。
- 判断是否有人物 / 主体。
- 判断是否有处境 / 设定。
- 判断是否有冲突 / 压力 / 代价。
- 判断是否有开发方向。

不能做：

- 不评价完整结构。
- 不评价人物弧线。
- 不评价类型完成度。
- 不强行给完整修改方案。

nextStep 倾向：

- 信息量不足但方向可辨时，优先使用「建议补充材料」。
- 已有清楚前提但仍不稳定时，使用「建议继续打磨」。
- 第一版通常不应直接进入下一阶段评估。

### 2. 故事概念 / 创意前提

对应 `materialForm`：`concept`

典型字数：80-600 字。

诊断目标：

- 判断前提是否有张力。
- 判断人物、处境、冲突是否可辨认。
- 判断是否值得扩展成梗概或大纲。

不能做：

- 不按完整故事结构裁定成败。
- 不强行要求完整结尾。
- 不评价对白、场次、节奏执行。

nextStep 倾向：

- 「建议补充材料」
- 「建议继续打磨」

通常不应直接进入下一阶段评估。

### 3. 故事梗概

对应 `materialForm`：`synopsis`

诊断目标：

- 判断主角、目标、冲突、转折、结尾方向是否清楚。
- 判断因果链是否稳定。
- 判断是否具备扩展为大纲或剧本的基础。

不能做：

- 不按完整剧本标准评价场次、对白、执行细节。
- 不因为缺少分场细节就判定材料失败。
- 不直接评价制作可行性或投递价值。

nextStep 倾向：

- 核心人物、冲突、走向不足时，使用「建议补充材料」或「建议继续打磨」。
- 因果链断裂、反转缺少铺垫、关键动机不成立时，不应轻易使用「可进入下一阶段评估」。

### 4. 故事大纲

对应 `materialForm`：`outline`

诊断目标：

- 判断主线、副线、阶段推进、关键转折、中段支撑、结尾回应。
- 长片方向大纲必须重点看：反派动机、关键因果、巧合依赖、人物支线转变。

不能做：

- 不按完整剧本的对白、场次细节或镜头执行判断。
- 不把大纲缺少具体场面等同于故事不成立。

nextStep 要求：

- 只有结构稳定、因果链清楚、关键转折有铺垫，才可考虑「可进入下一阶段评估」。
- 如果存在反派动机薄弱、关键巧合依赖、转折铺垫不足、中段支撑不稳，应优先使用「建议继续打磨」或「需要重新开发」。

### 5. 人物小传

对应 `materialForm`：`character_bio`

诊断目标：

- 判断人物欲望、创伤、关系、矛盾、行动可能性。
- 判断是否能发展出故事事件。

不能做：

- 不评价完整故事结构。
- 不评价结尾是否成立。
- 不要求人物小传已经包含完整情节链。

nextStep 倾向：

- 建议补充故事起点事件。
- 建议补充人物与外部冲突的连接。
- 建议明确人物欲望、压力来源和行动可能性。

### 6. 世界观设定

对应 `materialForm`：`worldbuilding`

诊断目标：

- 判断规则、制度、代价、社会结构、潜在冲突是否清楚。
- 判断是否能落到具体人物处境。

不能做：

- 不硬找主角弧线。
- 不评价完整剧本结构。
- 不把设定丰富度直接等同于故事成立。

nextStep 倾向：

- 建议补充核心人物。
- 建议补充事件起点。
- 建议说明规则如何给人物制造压力、代价或选择。

### 7. 剧本片段 / 局部场景

对应 `materialForm`：`fragment`

诊断目标：

- 判断局部场景是否有效。
- 判断人物互动、冲突、情绪、对白、动作是否成立。

不能做：

- 不把片段当完整剧本。
- 不评价完整结构。
- 不直接判定短片或长片完成度。

nextStep 倾向：

- 建议补充前后场次。
- 建议明确片段在整体故事中的功能。
- 建议说明片段承载的是人物关系、情绪转折、信息揭示还是冲突升级。

### 8. 完整短片剧本

对应关系：`materialForm=full_script` + `targetFormat=short`

诊断目标：

- 判断短片叙事模式。
- 判断核心表达、情绪路径、压力递进、结尾类型、手法成立性。

注意：

- 不机械要求主角强主动。
- 观察型、情绪流型、困境型、循环型、开放式结尾都可成立。
- 重点看手法是否有支撑。
- 结尾不一定要给明确答案，但必须有情绪落点、表达落点或形式上的回应。

### 9. 完整长片剧本

对应关系：`materialForm=full_script` + `targetFormat=feature`

诊断目标：

- 判断主线贯穿。
- 判断主角目标持续。
- 判断冲突升级。
- 判断中段支撑。
- 判断人物关系推进。
- 判断关键转折效能。
- 判断结尾是否回应主线。

注意：

- 长片诊断不能只看前提强不强，必须看结构体量是否支撑。
- 如果中段缺少推进、反派动机不足、关键转折依赖巧合、人物支线无变化，即使设定有亮点，也不应给过高判断。

### 10. 未来：项目成熟度评估

当前未接入第三层。

未来第三层不是基础故事诊断，而是项目成熟度评估，可能包括：

- 制作可行性
- 市场方向
- 预算风险
- 演员 / 场景难度
- 投递建议
- 是否适合进入人才平台或项目池

当前基础诊断和进阶诊断不得正式裁定项目能否拍摄、是否有人投资、是否适合投递。

## 三、材料阶段与现有字段关系

当前系统已经开始拆分以下字段：

- `userSelectedType`：用户选择的目标方向。允许值为 `short`、`feature`、`other`。
- `targetFormat`：系统理解的目标作品方向。允许值为 `short`、`feature`、`unknown`。
- `materialForm`：材料实际形态。允许值包括 `full_script`、`outline`、`synopsis`、`concept`、`character_bio`、`worldbuilding`、`fragment`、`unknown`、`reject`。
- `effectiveDiagnosisType`：当前实际进入的诊断 prompt 类型。允许值为 `short`、`feature`、`other`、`reject`。

用户选择目标方向不等于最终诊断方式。目标方向只说明用户想把材料开发成什么，材料形态决定当前该用什么诊断标准。

示例：

- 用户选长片，但上传长片梗概：`targetFormat=feature`，`materialForm=synopsis`，`effectiveDiagnosisType=other`。
- 用户选短片，但上传局部片段：`targetFormat=short`，`materialForm=fragment`，`effectiveDiagnosisType=other`。
- 用户选短片，上传完整短片剧本：`targetFormat=short`，`materialForm=full_script`，`effectiveDiagnosisType=short`。

当前路由原则：

- `materialForm=reject`：拒绝进入诊断。
- `full_script + targetFormat=short`：进入短片剧本诊断。
- `full_script + targetFormat=feature`：进入长片剧本诊断。
- `outline / synopsis / concept / character_bio / worldbuilding / fragment / unknown`：进入创意材料诊断。

## 四、当前测试暴露的问题

### 1. 长片梗概 / 大纲 nextStep 偏乐观

样本如《沉没的摇篮》《蜂鸟行动》。

问题：

- 创意材料诊断对长片方向梗概 / 大纲的「可进入下一阶段评估」门槛偏松。
- 存在关键因果、反派动机、反转铺垫问题时，不应轻易给高判断。

后续方向：

- `other` 诊断需要根据 `targetFormat=feature` 收紧长片方向梗概 / 大纲的 nextStep。
- 大纲与梗概的高判断条件应明确包含因果链、反派动机、关键转折铺垫和中段支撑。

### 2. 极短短片概念被误判为 synopsis 后打回

样本如《最后的烤冷面》。

问题：

- 184 字但具备人物、处境、压力、结尾方向。
- 应更接近 `concept` 或极短概念初筛，不应直接按 `synopsis` 300 字门槛打回。

后续方向：

- `concept` 与 `synopsis` 的边界需要调整。
- 对极短但信息完整的概念，应允许进入概念层诊断，而不是因为达不到梗概字数被拒绝。

### 3. 空泛一句话概念被打回是合理的

样本如「一个年轻人离开城市回到老家……」。

说明：

- 信息不足，低于 `concept` 最低有效信息量，被打回合理。
- 后续不应为了接纳所有短文本而取消最低有效信息要求。

### 4. 剧本片段被误判为完整剧本

样本如《天台上的宇航员》。

问题：

- 有剧本格式不等于完整剧本。
- 单场或局部场景应更倾向 `fragment`。
- `full_script` 判断需要收紧。

后续方向：

- 完整剧本判断应同时看场景数量、连续情节推进、开端到结尾方向、文本体量和是否呈现完整故事。
- 不能只因对白、场景标题或剧本格式存在，就判定为完整剧本。

### 5. 世界观设定和人物小传表现较稳定

样本如《镜界公约》《季澜：深蓝的幻影》。

说明：

- 当前能正确识别为 `worldbuilding` / `character_bio`。
- 报告能正确提示补充人物、事件或故事起点。

后续方向：

- 保留当前识别方向。
- prompt 可继续强化：世界观设定看规则如何落到人物处境，人物小传看人物如何产生故事事件。

### 6. 短片完整剧本仍偶尔机械抓主角主动性

样本如《回声》。

问题：

- 对观察型 / 情绪流型 / 超自然余韵型短片，不应机械要求主角主动调查。
- 应改为判断观察者是否被事件触动、情绪落点是否充分、手法是否成立。

后续方向：

- 短片 prompt 继续减少「主角主动解决问题」的惯性。
- 对观察者、被困者、情绪承载者、被系统推动的人，应改看状态变化和表达落点。

## 五、nextStep 使用原则

### 基础诊断层

基础诊断回答的问题是：材料当前是否具备故事开发的基本资格。

允许前缀：

- 「建议补充材料」：材料与影视创意相关，但当前信息不足。适用于概念、人物小传、世界观设定、片段文本等。
- 「建议继续打磨」：材料已有基础，但核心人物、冲突、走向或结构仍需调整。
- 「需要大改」：材料已有雏形，但基础故事关系明显不成立。
- 「可进入进阶诊断」：材料具备更深入判断的条件。这个前缀会触发进阶诊断。
- 「不适合按长片诊断」：材料不适合作为长片剧本 / 网络电影进行基础诊断。
- 「不适合按创意材料诊断」：材料与影视创意明显无关。

### 进阶诊断层

进阶诊断回答的问题是：这个故事 / 材料是否真正成立，是否值得继续开发到下一阶段。

允许前缀：

- 「建议继续打磨」：方向成立，但存在具体可修改问题。
- 「需要结构性重写」：短片或长片已经具备故事基础，但结构、表达或执行路径存在结构性问题。
- 「可进入下一阶段评估」：材料已具备进入未来项目成熟度评估的基础。此项必须谨慎使用。
- 「暂不适合继续深化」：材料被错误送入进阶诊断，或基础条件仍明显不足。
- 「需要重新开发」：主要用于创意材料，表示核心前提、人物、冲突、走向之间存在根本性断裂。
- 「建议补充材料」：主要用于创意材料，表示方向不一定错误，但信息量不足。

### 分阶段 nextStep 边界

- 极短概念、人物小传、世界观设定、片段文本通常不应直接「可进入下一阶段评估」。
- 长片方向梗概 / 大纲只有在因果链、关键转折、反派或对抗力量、结尾方向都足够稳定时，才可考虑高判断。
- 完整短片剧本可以进入高判断，但必须确认叙事模式、压力递进、情绪落点或结尾类型成立。
- 完整长片剧本可以进入高判断，但必须确认主线贯穿、中段支撑、冲突升级和结尾回应。

## 六、后续改造建议

### 第一阶段：更新系统命名和规则文档

- 统一系统名称为「帧火花故事开发诊断系统」。
- 明确材料阶段诊断边界。
- 明确不同阶段的 nextStep 使用门槛。

### 第二阶段：修 materialRouter 边界

- 收紧 `full_script` vs `fragment`。
- 调整 `concept` vs `synopsis`。
- 调整 `synopsis` vs `outline`。
- 修 `guard` 对极短概念的准入规则。
- 保留本地规则 + 轻量 AI 辅助识别，AI 只判断 `materialForm`，最终路由仍由本地代码决定。

### 第三阶段：改 prompt

- `other` 诊断按材料阶段输出，而不是把概念、梗概、大纲、人物小传、世界观设定、片段文本混用同一套标准。
- 长片梗概 / 大纲收紧 nextStep。
- 短片诊断继续减少机械主角主动性。
- 对目标方向 `targetFormat` 的使用更明确：目标方向影响建议口径，但不改变材料阶段。

### 第四阶段：报告可信度优化

- 增加系统理解校验层，让报告开头说明系统识别到的材料阶段和目标方向。
- 列表字段条件性输出，不强制凑亮点 / 问题 / 建议。
- 增加「理解有误」反馈按钮，反馈进入日志。
- 诊断日志记录用户反馈、材料形态识别来源、模型判断和前端展示结果，便于后续质检。
