# 故事开发诊断系统样本测试归档

本目录用于保存故事开发诊断系统的样本测试与结果对照。

## 使用方式

- 每轮测试一个日期目录，例如 `2026-05-21-manual-001`。
- 使用 `npm run samples:new` 创建新的空白测试目录。
- 样本可人工填写，后续也可扩展为 AI 自动生成或辅助整理。
- 当前目录只用于归档测试样本、系统输出结果和人工复盘，不用于线上运行。

## 隐私与提交规则

- 不应默认提交真实用户敏感原文到仓库，除非确认有权限。
- 日期测试运行目录默认被 `.gitignore` 忽略。
- 可提交的内容应以模板、说明文档和不含敏感内容的测试框架为主。

## 模板

模板文件位于 `templates/`：

- `samples.md`
- `samples.json`
- `results.md`
- `results.json`
- `review-notes.md`
