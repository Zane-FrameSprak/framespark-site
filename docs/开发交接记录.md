## 当前架构原则

- 首页骨架放在 `index.html`
- 视觉样式放在 `css/style.css`
- 首页内容数据放在 `js/site-data.js`
- 页面交互放在 `js/main.js`
- 后续常改内容尽量不写死在 HTML 中
- 项目、平台、生态优先通过数据新增

## AI 协作方式

- GitHub 仓库是 Mac / Windows / Claude Code / Codex 之间的唯一同步源。
- Claude Code 和 Codex 不共享聊天记忆，只共享仓库中的代码、文档、提交记录和远程分支状态。
- 不建议两个 AI 同时修改同一个项目，避免上下文不一致、代码互相覆盖或方向漂移。
- 每次切换 AI 前，当前 AI 应完成：
  - 检查 `git status`
  - 更新本交接记录
  - commit 并 push 到 GitHub
- 下一个 AI 开始工作前，应先 pull 最新代码，并阅读：
  - `README.md`
  - `docs/内容维护说明.md`
  - `docs/开发交接记录.md`
- 重要想法、阶段判断和项目规则应沉淀到仓库文档中，不依赖单个聊天窗口的上下文。
- 旧版 Word / PDF 资料仅作历史参考，不自动覆盖当前仓库实现；当前项目推进以本 GitHub 仓库内容为准。

## 后续新增项目的方法

在 `js/site-data.js` 的 `FrameSparkData.projects` 中新增：

```js
{
    type: '项目类型',
    title: '《项目名称》',
    duration: '时长或说明',
    cover: 'assets/projects/project-cover.jpg',
    href: 'projects/project-name.html'
}
```

如果要新建项目详情页，复制：

```text
projects/template.html
```
