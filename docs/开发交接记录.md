## 当前架构原则

- 首页骨架放在 `index.html`
- 视觉样式放在 `css/style.css`
- 首页内容数据放在 `js/site-data.js`
- 页面交互放在 `js/main.js`
- 后续常改内容尽量不写死在 HTML 中
- 项目、平台、生态优先通过数据新增

## 后续新增项目的方法

在 `js/site-data.js` 的 `FrameSparkData.projects` 中新增：

```js
{
    type: '项目类型',
    title: '《项目名称》',
    duration: '时长或说明',
    cover: 'assets/projects/project-cover.jpg',
    href: 'projects/project-name.html'
}
```

如果要新建项目详情页，复制：

```text
projects/template.html
```
