# 帧火花官网内容维护说明

当前官网是可扩展静态站点骨架。页面结构、样式、内容数据、交互逻辑分开维护：

```text
index.html       首页骨架
css/style.css    全站视觉样式
js/site-data.js  首页可维护内容数据
js/main.js       首页交互和数据渲染
```

## 目录结构

```text
framespark/
├─ index.html
├─ 404.html
├─ robots.txt
├─ sitemap.xml
├─ site.webmanifest
├─ assets/
│  ├─ brand/             # favicon 等品牌资产
│  └─ projects/          # 后续项目封面建议放这里

│  ├─ privacy.html

   └─ 内容维护说明.md
```

## 新增项目展示

在 `js/site-data.js` 的 `FrameSparkData.projects` 里新增一条：

```js
{
    type: '院线电影',
    title: '《项目名称》',
    duration: '时长 100-120min',
    cover: 'assets/projects/project-cover.jpg',
    href: 'projects/project-name.html'
}
```

字段说明：

- `type`：项目类型，例如短片、网络电影、院线电影、流媒体剧集
- `title`：项目名称
- `duration`：时长或补充说明
- `cover`：封面图片路径；没有封面时留空，会显示编号占位
- `href`：项目详情页路径；没有详情页时留空

项目跑马灯会自动复制一组卡片用于无缝滚动，不需要手动写两遍。

## 新增项目详情页

复制：

```text
projects/template.html
```

改名为：

```text
projects/project-name.html
```

然后在 `js/site-data.js` 对应项目里填：

```js
href: 'projects/project-name.html'
```

## 修改系统与平台

在 `js/site-data.js` 的 `FrameSparkData.platforms` 里修改或新增：

```js
{
    number: '03',
    status: '开发中',
    title: '新平台名称',
    freeLabel: '',
    english: 'ENGLISH NAME',
    description: '一句说明文字。',
    href: 'new-module/'
}
```

字段说明：

- `freeLabel` 写 `'免费'` 会显示免费标签
- `freeLabel` 留空则不显示，但会保留排版占位
- `href` 填页面路径后，整张平台卡片可点击

## 封面图片建议

项目封面建议放在：

```text
assets/projects/
```

推荐比例：`3:4`。

推荐命名：

```text
assets/projects/gongxi.jpg
assets/projects/listing-eve.jpg
```

## 法律页面


正式上线前需要根据实际功能和律师意见替换内容。

## 上线相关文件

```text
assets/brand/favicon.svg
site.webmanifest
robots.txt
sitemap.xml
```

如果正式域名不是 `https://framespark.cn/`，需要同步修改：

- `index.html` 里的 `canonical` 和 `og:url`
- `robots.txt` 里的 `Sitemap`
- `sitemap.xml` 里的所有 `loc`

## 不建议直接改的地方

- 不建议在 `index.html` 里手写项目卡片
- 不建议复制项目卡片做跑马灯
- 不建议把项目内容写进 `css/style.css`
- 不建议把首页数据重新分散回 HTML
